# Agent Instructions

## Language

All repository content must be written in English.

This rule applies to all content created or modified in this repository, including:

- Source code identifiers where naming is under our control
- Code comments
- Documentation and README files
- Configuration files and explanatory comments
- SQL scripts and comments
- Tests and test descriptions
- Commit messages
- Pull request titles and descriptions
- Issue titles and descriptions
- Agent-generated plans, notes, and artifacts stored in the repository

Do not introduce Spanish or other languages into repository content unless a specific requirement explicitly requires localized or multilingual content.
